CAPCUT STRIPPED - WHAT'S NEW
============================

(Earlier versions were called "CapCut Lite".)


VERSION 1.2.0  -  Way smaller

  - CapCut is now compressed on disk with Windows' own compression.
    The program drops from 1,849 MB to about 540 MB and works exactly
    the same.
  - A real progress bar shows how far the compression is.
  - Removed parts are deleted for good instead of kept in a backup
    folder. The old backup folder (CapCut\_removed) is deleted too.
  - Fresh installs had a second EditPilot button. Hidden now.
  - On CapCut's newer home screen, Projects sits right under
    "Create project" again (no empty gap).
  - The Undo file is gone. To get normal CapCut back, reinstall it.


VERSION 1.1.0  -  No more AI buttons and Pro ads

  The new "CapCut Stripped" desktop shortcut hides all of this:

  In the editor:
  - EditPilot button (bottom right)
  - "Generate" row in the left sidebar
  - "AI avatar" tab
  - "No media? Create with these tools" cards
  - "AI clipper / Try for free" bar
  - "AI extend" button and the AI extend handle on clips
  - "AI edit" magic wand button
  - "AI stylize" tab when a clip is selected

  Pro / Ultra ads:
  - "Get 7 days free Pro" button at the top right
  - Start pop-ups: "CapCut Pro", "7-day free trial",
    "Try CapCut Pro for free", "CapCut Ultra is live" and others

  Fixes:
  - Online stickers and effects said "No internet connection".
    Fixed: CapCut's own files stay original now, the shortcut makes
    the changes only while CapCut runs.
  - Online materials broke because two download folders were blocked.
    Not blocked any more.


VERSION 1.0.0  -  First version

  - Smaller CapCut: AI agent, AI models, extra languages, crash
    reports, auto-updater, promo pages and old caches removed.
  - Home screen: AI cards and AI section removed, Projects moved up,
    sidebar promo banners removed.
  - Offline mode ON / OFF files.
